Play the code-anchored walkthroughs your coding agent publishes, step by step next to the highlighted code in Rider.

Instead of pasting code excerpts into its reply, the agent saves a walkthrough in your project and gives you one link. Rider opens it in the Walk Me Through tool window: an outline, a Markdown explanation for each step, and a precise highlight in the current editor.

Get started

  1. Install JetBrains Toolbox if you don't have it; it delivers jetbrains:// links to Rider.
  2. Open your project and run Walk Me Through: Install Skill into Project (Find Action). It copies the project skill shipped inside this plugin into .agents/skills/walk-me-through/ at the Git root, without network access or Node.
  3. Commit that folder and restart your agent (for example OpenCode) so it discovers the skill.
  4. Ask the agent to explain something that spans several files, click the link in its reply, and choose Open in Rider.

The project skill

  • The install command adds only missing files. If a skill file already exists with different content, it changes nothing and names that file.
  • When a Git project without the skill opens, a notification offers Install, Not for This Project and Don't Ask Again. These choices are stored in Rider's own settings, never in the project.
  • While the skill is missing, the tool window shows a banner with Install Skill, even after the offer was dismissed.

Reading a walkthrough

Use Next, Previous, Skip Details and Return, or pick any step in the outline. Walk Me Through: Open Walkthrough lists the project's saved walkthroughs by title and ID. When code has changed since the walkthrough was written, moved code is followed, uncertain matches are marked, and missing code is reported instead of highlighting something else.

Launch links

A link opens the walkthrough only in a Rider window that already has the recorded project open. The plugin never opens projects or runs anything; other links only show a notice.

Platforms and privacy

  • Local desktop Rider on native Windows, Linux or macOS, with the bundled Web Browser (JCEF) enabled. Windows is tested by the maintainers; Linux and macOS are supported but not verified by the maintainers.
  • Not supported: remote development hosts, SSH, WSL, containers and headless IDEs.
  • Walkthroughs are JSON files in the project's self-ignoring .walk-me-through/ folder. The plugin makes no network requests of its own and collects no telemetry.
