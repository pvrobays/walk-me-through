# Bundled renderer assets

`highlight.min.js`: highlight.js 11.11.1 common-language browser build, BSD-3-Clause.
Downloaded from https://cdnjs.cloudflare.com/ajax/libs/highlight.js/11.11.1/highlight.min.js.
`LICENSE.highlight.js`: upstream license from the 11.11.1 tag.

Assets are packaged with the plugin and embedded in its generated document. Playback does not contact the CDN. CommonMark Java 0.24.0 (BSD-2-Clause) parses Markdown; raw HTML is escaped and images are omitted. Native controls do not use a JavaScript bridge.
