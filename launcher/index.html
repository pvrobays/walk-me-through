Nothing happened in VS Code?

This page cannot tell whether VS Code or the Walk Me Through extension is installed.

  • Install the Walk Me Through VS Code extension, then retry.
  • VS Code asks once whether the extension may open this link. Choose Open.
  • The link goes to the VS Code window you used last. Open the project folder shown above in it, then retry.
  • On Linux, VS Code installed from a .tar.gz archive does not register vscode:// links.

Nothing happened in Rider?

This page cannot tell whether Rider or the Walk Me Through plugin is installed.

  • Rider links need JetBrains Toolbox (its jetbrainsd link handler) to be installed.
  • Install the Walk Me Through Rider plugin, then retry.
  • Open the project shown above in Rider, then retry. If Rider was closed, it starts without opening the project.
  • The Rider plugin currently supports native Windows only.
